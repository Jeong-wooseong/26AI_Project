# ReplyBoss 서비스 안내서 (도우미 참고용)

## ReplyBoss가 동작하는 방식
- 사장님 브라우저(화면) → ReplyBoss 서버 → OpenAI(AI) 순서로 요청이 오갑니다. 셋 중 하나라도 연결이 끊기면 리뷰 분류, 답글 초안 생성, 말투 분석, 주간 리포트 AI 요약, 도우미 AI 답변이 되지 않습니다.
- 리뷰 목록 보기, 작성 완료한 답글 복사·수정처럼 AI가 필요 없는 기능은 ReplyBoss 서버에만 연결되면 됩니다.
- 인터넷이 끊기면 화면에 "서버에 연결할 수 없습니다"(오류 코드 NETWORK)가 나오고, 어떤 기능도 저장되지 않습니다.
- 배달앱·지도와는 연결되어 있지 않습니다. 리뷰는 사장님이 직접 넣고, 답글도 사장님이 복사해 직접 게시합니다.

## 인터넷·연결 문제일 때 확인할 것
1. 와이파이나 유선 인터넷이 연결되어 있는지, 다른 사이트가 열리는지 확인합니다.
2. 회사·매장 와이파이에서 특정 사이트를 막아 둔 경우가 있습니다. 휴대폰 데이터 등 다른 네트워크로 시도해 봅니다.
3. 브라우저를 새로고침(F5)합니다. 오래 열어 둔 화면은 로그인이 풀렸을 수 있습니다.
4. 그래도 "서버에 연결할 수 없습니다"가 나오면 ReplyBoss 서버가 꺼져 있거나 점검 중일 수 있습니다. 잠시 뒤 다시 시도하고, 계속되면 오류 제보를 남깁니다.
- 연결이 끊긴 동안 입력하던 내용은 서버에 저장되지 않았을 수 있습니다. 다시 연결되면 목록에서 등록 여부를 확인한 뒤, 없으면 다시 등록합니다(중복으로 들어갔다면 리뷰 삭제 버튼으로 지울 수 있습니다).

## 답글 생성이 느리거나 안 될 때
- 답글 초안 3개(정중형·친근형·간결형)를 만드는 데 보통 5~20초가 걸립니다. 겹치는 표현이나 규칙 위반이 있으면 최대 2번 다시 만들어서 더 걸릴 수 있습니다.
- 답글 일괄 처리는 한 건씩 차례로 처리하므로 리뷰 수만큼 시간이 걸립니다. 중간에 멈추기를 눌러도 이미 처리한 건은 저장되어 있습니다.
- 오류 코드별 의미
  - LLM_TIMEOUT: AI 응답이 늦어 시간이 초과됨. 잠시 뒤 다시 시도.
  - LLM_RATE_LIMIT, LLM_HTTP_429: 짧은 시간에 요청이 많음. 1분쯤 뒤 다시 시도.
  - LLM_QUOTA: 서비스의 AI 사용 한도·크레딧이 소진됨. 사장님이 해결할 수 없으므로 오류 제보 필요(운영자 확인).
  - LLM_HTTP_401, LLM_HTTP_403, LLM_NOT_CONFIGURED: 서비스의 AI 연결 설정 문제. 오류 제보 필요(운영자 확인).
  - LLM_HTTP_5xx: AI 회사 서버 일시 오류. 잠시 뒤 다시 시도.
  - LLM_UNSAFE: 리뷰 내용 때문에 규칙에 맞는 답글을 만들기 어려움. 다시 생성하거나 직접 작성.
  - LLM_INVALID, LLM_TRUNCATED, LLM_FAILED: 일시적인 AI 응답 문제. 다시 시도.
  - NOT_DRAFT_TARGET: 칭찬·불만·문의가 아닌 리뷰(악성·별점만)는 답글 초안 대신 대응 가이드나 템플릿을 씀.
  - NETWORK: 인터넷 또는 ReplyBoss 서버 연결 문제.

## 로그인·계정
- 로그인 상태는 '로그인 상태 유지'를 켜면 14일, 끄면 브라우저를 닫거나 2시간 동안 쓰지 않으면 풀립니다. 풀리면 로그인 화면으로 돌아갑니다(오류 코드 UNAUTHORIZED).
- "보안 토큰이 없거나 만료되었습니다"(CSRF)가 나오면 새로고침한 뒤 다시 시도합니다.
- 비밀번호를 5번 틀리면 10분 동안 로그인할 수 없습니다(LOGIN_LOCKED). 기다리거나 비밀번호 찾기로 재설정합니다.
- 인증 메일·재설정 메일은 보통 몇 분 안에 옵니다. 스팸함을 확인하고, 로그인 화면에서 다시 받을 수 있습니다. MAIL_NOT_CONFIGURED·MAIL_FAILED는 서비스 메일 설정 문제라 오류 제보가 필요합니다.
- 비밀번호는 8자 이상, 영문과 숫자를 모두 포함해야 합니다.

## 입력 제한과 형식
- 한 번에 등록할 수 있는 리뷰는 30건, 리뷰 한 건은 2000자까지입니다.
- 파일 가져오기는 CSV·엑셀(xlsx) 파일을 브라우저 안에서 읽습니다. 파일 자체는 서버로 올라가지 않고, 읽은 리뷰만 등록됩니다.
- 예시 답글은 3~5개, 매장 소개·운영 방식은 500자까지입니다.
- 문의 첨부는 PNG·JPG·GIF·WEBP 이미지 1장, 5MB까지입니다.
- 리뷰 속 전화번호·이메일·주소·주문번호는 자동으로 가려지고, 가린 문장만 AI에 보내고 저장합니다.

## 권장 환경
- 크롬·엣지·사파리·웨일 최신 버전을 권장합니다. 오래된 인터넷 익스플로러는 지원하지 않습니다.
- 화면이 이상하면 새로고침하거나 다른 브라우저로 열어 봅니다. 브라우저 확장 프로그램(광고 차단 등)이 요청을 막는 경우도 있습니다.
- 휴대폰에서도 쓸 수 있지만, 여러 리뷰를 다룰 때는 PC가 편합니다.

## 주요 기능 요약
- 리뷰 입력: 직접 입력, 여러 리뷰 붙여넣기, 파일 가져오기. 등록하면 칭찬·불만·악성·문의·별점만으로 분류합니다.
- 오늘의 리뷰: 작성 완료 / 작성 대기 / 분류 실패 탭. 작성 대기에서 초안을 고르고 '작성 완료'를 누릅니다. 날짜·출처·유형으로 거르고 검색할 수 있습니다.
- 답글 일괄 처리: 작성 대기 리뷰를 고른 말투로 한 번에 작성 완료하거나 초안만 만듭니다. 불만·악성은 체크할 때만 포함하고, 악성은 대응 초안만 만듭니다.
- 리뷰 삭제: 잘못 입력했거나 중복 등록한 리뷰는 휴지통 버튼으로 지웁니다. 답글도 함께 지워지고 되돌릴 수 없습니다.
- 악성 리뷰: 대응 가이드(사과 후 마무리 / 사실 관계 설명 / 응대 보류·신고 검토)와 확인할 점, 대응 답글 초안을 줍니다. 확인 체크 후 작성 완료합니다.
- 주간 리포트: 월~일 단위 리뷰 수, 평균 별점, 불만 주제 순위, 지난주와 비교(좋아진 점·나빠진 점), 답글 현황. AI 요약은 버튼을 눌러 만듭니다.
- 답글 피드백: 초안·최종 답글마다 '마음에 들어요 / 개선하고 싶어요'를 남기면 품질 개선에 쓰입니다.
- 고객 지원: 자주 묻는 질문, 문의하기(일반·오류 제보·개선 제안), 내 문의에서 처리 상태와 답변 확인.
